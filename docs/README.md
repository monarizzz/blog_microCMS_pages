# ドキュメント

このプロジェクトの**設計思想・アーキテクチャ・技術的な意思決定**をまとめた場所です。個々の設計ドキュメントは `architecture/` 以下に置いています。

## architecture/ — 基盤設計

技術スタック、ディレクトリ構造、データモデル、コンポーネント設計など、システムの土台となる設計をまとめています。

- [directory-structure.md](architecture/directory-structure.md) … ディレクトリ構造の設計
- [component-structure.md](architecture/component-structure.md) … コンポーネント設計（作成中）
- [data-model.md](architecture/data-model.md) … microCMS コンテンツモデル（API・フィールド定義）

## デザイン成果物の場所

UI・デザイントークン・生成プロンプトなどのビジュアル成果物は [`../design/`](../design/) にあります。**最新は番号が最も大きいバージョンディレクトリ**（`design/v3/` など）を参照してください。詳細は [design/README.md](../design/README.md) を見てください。
