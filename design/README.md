# design ディレクトリ

**UI・ビジュアルデザインの成果物**（Pencil ファイル・デザイントークン・生成プロンプト・プレビュー画像）を置く場所です。
文章ベースの設計・アーキテクチャ・意思決定は [`../docs/`](../docs/) にあります。

## 最新版の見つけ方

**最新のデザインは `design/` 直下でもっとも番号が大きいバージョンディレクトリ**（`v2`, `v3`, … の最大値）です。
過去バージョンは経緯確認のために残していますが、**実装・レビューは常に最新版（最大番号）を正**とします。
大幅なデザイン改修をするときだけ、次の番号のディレクトリを切ってください。

> 番号を直接書いていないため、この README はバージョンが上がっても書き換え不要です。

## ファイル構成（最新版の基準）

デザインは「入力 → 仕様 → 実装 → 適用 → 確認」の順に並んでいます。

| ファイル | 役割 |
| --- | --- |
| `DESIGN_PROMPT.md` | ① 生成の入力プロンプト（再現用） |
| `DESIGN.md` | ② デザイントークン仕様（SSOT・人間可読） |
| `design-tokens.css` | ③ ②から得た実装値（CSS 変数） |
| `ui.pen` | ④ ②を適用した画面デザイン（Pencil） |
| `image.png` | ⑤ 完成イメージ |

※ 旧バージョンはファイル構成が異なる場合があります（当時の成果物のまま残しています）。

## 注意

- `.pen` は Pencil 専用の暗号化形式です。エディタ（Pencil）で開いてください。
